# Changelog

All notable changes to Calendar Pro will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2026.5.20.5] - 2026-05-22

### Added

- Initial public release on Microsoft Marketplace.
- Date range selector with day, week, pay period, month, quarter, year granularities.
- Preset ranges including today, this/last week, this/last month, this/last quarter,
  year-to-date variants, and last-N-days options.
- Configurable week start day, year start month, and pay-period reference.
- Light and dark theme support.
- Synchronization with other Power BI visuals via the host filter API.
- Bookmark support for persisting filter state.
- Five locales: en-AU, en-US, es-ES, fr-FR, nl-NL.
